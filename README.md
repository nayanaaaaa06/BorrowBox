# BorrowBox — Borrow Better

BorrowBox is a web-based item lending platform that allows users to list items, request to borrow items from others, and manage lending transactions.

## Live Demo
https://borrowbox-7122f.web.app

## Features
- User authentication with Firebase Authentication
- Browse and list items
- Request items and manage borrowing requests
- Support for free and paid lending
- Manual UPI or cash payment tracking
- Chat between borrowers and item owners
- Track active loans and returns
- Reviews and ratings
- Admin dashboard

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting

## Database
Cloud Firestore (NoSQL document database).

## How to Run Locally
1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Sign in to use the application.
